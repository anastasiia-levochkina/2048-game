# 2048 Game

## 📌 Project Overview

This project is a browser implementation of the classic **2048 puzzle game**.
Players move numbered tiles on a 4×4 grid using keyboard arrows. When two tiles with the same value collide, they merge into one tile with the doubled value. The goal is to reach the **2048 tile** while maximizing the score.

The game includes dynamic tile generation, merging logic, score tracking, win/lose states, and simple animations for tile appearance and merging.

## ▶️ How to Run Locally

Clone the repository:

```bash
git clone https://github.com/anastasiia-levochkina/2048-game.git
```

Navigate to the project folder:

```bash
cd 2048-game
```

Install dependencies:

```bash
npm install
```

Run the project locally:

```bash
npm start
```
